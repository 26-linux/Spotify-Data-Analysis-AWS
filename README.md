#  Spotify Data Analysis using AWS

##  Project Overview

This project analyzes **Spotify 2023 tracks, albums, and artists data** to generate meaningful insights from a large-scale dataset of **400,000+ tracks**.

The project implements an end-to-end data pipeline using **AWS S3, AWS Glue (Spark), Snowflake, and Power BI**. Raw data is stored in S3, transformed using AWS Glue, analyzed using Snowflake SQL, and visualized through an interactive Power BI dashboard.

##  Tools & Technologies

 **AWS S3** – Storage for raw and processed datasets,
 **AWS Glue** – ETL processing using Apache Spark,
 **Snowflake** – Data transformation, storage, and SQL analysis,
 **Snowflake ODBC** – Connectivity between Snowflake and Power BI,
 **Power BI** – Interactive dashboards and data visualization

##  Key Outcomes

* Analyzed **400,000+ Spotify tracks** across global datasets.
* Built a **scalable and automated ETL pipeline** using AWS Glue and Snowflake.
* Performed data transformation and analytical queries using **Spark and Snowflake SQL**.
* Created interactive **Power BI dashboards** to explore trends across artists, albums, tracks, and countries.
* Developed an end-to-end data pipeline covering **data storage → ETL → transformation → analysis → visualization**.

##  Project Workflow

**Spotify Dataset → AWS S3 → AWS Glue (Spark ETL) → Snowflake → Snowflake SQL → ODBC → Power BI**

##  Project Goal

The goal of this project is to demonstrate an end-to-end **cloud-based data engineering and analytics workflow** using AWS, Snowflake, and Power BI to transform raw music data into meaningful business insights.
